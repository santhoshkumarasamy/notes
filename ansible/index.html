Ansible Notes

A simple guide to configuring SSH authentication and creating your first Ansible inventory.

🔐 Configure Password-less SSH

This isn't truly password-less authentication. Instead, you'll generate an SSH key pair and configure Ansible to authenticate using the private key.

Generate an SSH Key

ssh-keygen -t ed25519 -a 100 -f ~/.ssh/my-server-key -C "prod-server"
Next Step: Copy the generated public key (my-server-key.pub) to the authorized_keys file on the target server.

⚙️ Install Ansible

Install Ansible using Python's package manager.

python3 -m pip install ansible
Note: If pip is not installed, install it before running the command above.

📁 Creating an Inventory File

Ansible supports inventory files in both INI and YAML formats.

This guide recommends using YAML because it is cleaner and easier to maintain.

Inventory Structure


all:
    vars:
    children:
        [group]:
        vars:
        hosts:
            [your-own-hostname]:

🖥️ Sample Inventory

Below is an example inventory for a group named webservers. 


all:
    children:
        webservers:
        vars:
            ansible_ssh_private_key_file: /home/ec2-user/.ssh/my-server-key
            ansible_user: ec2-user

        hosts:
            host1:
            ansible_host: 172.31.20.235

✅ Summary

  • Generate an SSH key pair.
  • Copy the public key to the remote server.
  • Install Ansible using pip.
  • Create an inventory file (preferably YAML).
  • Specify the SSH user and private key in the inventory.
  • Run Ansible playbooks using the configured inventory.
